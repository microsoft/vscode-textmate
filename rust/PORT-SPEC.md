# vscode-textmate 9.3.2 -> Rust: port spec (extracted from the 9.3.2 npm bundle `release/main.js`, pretty-printed and not shipped, and its TS sources, cross-checked)

Crate: `vscode-textmate` (Cargo.toml: onig_sys =69.8.1 with default-features = false, which builds Oniguruma 6.9.8, the sources vscode-oniguruma 1.7.0 compiles; rustc-hash 2.1.3; edition 2024). All modules are written. `src/onig_lib.rs`: OnigLib/OnigScanner traits, OnigString with UTF-16<->UTF-8 maps, NativeOnigLib on C Oniguruma (regset POSITION_LEAD search for u8len<1000, per-regex cached search otherwise, unmatched groups clamp via `b as u32 as i64`; `onig_initialize` once under `std::sync::Once` before the first `onig_new`, since Oniguruma's lazy init is unlocked and races across threads; patterns Oniguruma rejects behave as in vscode-oniguruma 1.7.0's onig.cc: `create_onig_scanner` never fails, a regex that doesn't compile is null and the regset is built only when every regex compiled (`onig_regset_new` also rejects a set holding a `(?L)` regex); for u8len<1000 a null set gives `{index 0, [[pos, pos]]}` when every regex is null and no match otherwise, and for longer strings null regexes never match; `try_create_onig_scanner` returns the error instead).
Written only from 9.3.2's TS sources and bundle; no code or decisions from other Rust TextMate ports.
Then brought up to main (98cc633): #252 (an empty or missing `end` is "", not U+FFFF), #261 (TokenHandler, a refactor) and #276 (fewer characters escaped); the rest of main since 9.3.2 doesn't change tokenizing.
Build: `cargo build --release`. json.rs is its own ordered JSON parser (no indexmap or serde_json).
Files: lib.rs, onig_lib.rs, json.rs (ordered JSON + plist), utils.rs (utils, EncodedTokenAttributes, FontAttribute, matcher, basic scopes), raw.rs (raw grammar, initGrammar, mergeObjects, parseRawGrammar), theme.rs, rule.rs (rules, RegExpSource, RuleFactory), grammar.rs (grammar, stacks, LineTokens, LineFonts, tokenizeString, dependencies, registry), diff_state_stacks.rs; bin/oracle.rs, bin/upstream_tests.rs, bin/parse_check.rs, bin/pattern_sweep.rs, bin/engine_probe.rs, bin/garbage_probe.rs, bin/invalid_grammar.rs (with probe/); tests/upstream_{json,grammar,matcher}.rs, tests/threads.rs; examples/tokenize.rs.

## BasicScopeAttributesProvider(langId, embedded)
defaults (langId, 8); null scope -> (0,0); cache per scope. lang = value of LONGEST embedded key k with scope==k or scope starts with k+"."; else 0. type = leftmost match of `\b(comment|string|regex|meta\.embedded)\b` (ASCII word boundary before/after, alternatives in order): comment 1, string 2, regex 3, meta.embedded 0, none 8.

## Matcher
Tokenizer `/([LR]:|[\w\.:][\w\.:\-]*|[\,\|\-\(\)])/g`: at each pos try L/R + ':'; else ident start [A-Za-z0-9_.:] + [A-Za-z0-9_.:-]*; else one of `,|-()`; else skip char. isIdentifier(t) = contains any [A-Za-z0-9_.:].
createMatchers: tok=next(); while tok { prio=0; if tok.len==2 && tok[1]==':' { prio = R->1 / L->-1 / else 0; tok=next() } push({conj(), prio}); if tok != "," break; tok=next() }.
operand: '-' -> next; e=operand(); result e.is_some() && !e(x). '(' -> next; inner(); if tok==')' next. identifier -> collect ids while identifier -> Name(ids). else None.
conj = And(operands until None) (empty And true). inner: list=[]; m=conj(); loop { push m; if tok is | or , { do next while tok is | or ,; m=conj() } else break } -> Or(list).
nameMatcher(ids, scopes): false if scopes.len < ids.len; ordered subsequence search from lastIndex; f(s,id) = s non-empty && (s==id || (s.len>id.len && s starts with id && s[id.len]=='.')).

## JSON (JS JSON.parse quirks)
Duplicate key: last value at first key's position. Canonical integer-like keys iterate first ascending, then others in insertion order (matters for captures and injections: first compile decides repository context of a shared raw rule). Truthiness: {} [] truthy; "" 0 falsy; applyEndPatternLast 1 true. Captures may be an array (indices are keys); non-object capture values -> empty rules. parse_json is strict like JSON.parse (a leading BOM is an error); only the plist parser skips a BOM. Lone surrogate escape -> U+FFFD.

## Theme
parseTheme: skip entries without settings. scope: string -> strip leading/trailing commas, split ','; array as is; else [""]. fontStyle -1 unless string -> 0 | italic 1 | bold 2 | underline 4 | strikethrough 8 (split ' '). fg/bg valid hex else None. Per scope: trim().split(' '); last = scope; parents = rest reversed, or None if one segment; index = entry index.
Sort by strcmp(scope), strArrCmp(parents), index. Shift leading scope=="" rules into defaults (start fs 0, fg #000000, bg #ffffff).
ColorMap.getId: None -> 0; uppercase; existing id or next from 1. Call order: defaults fg, bg; then per sorted rule fg, bg.
root = Trie(mainRule{depth 0, parents [], fs -1, fg 0, bg 0}, []); each rule insert(0, scope, parents, fs, id(fg), id(bg)).
insert(depth, scope,...): scope "" -> doInsertHere; else split at first '.'; child = existing or new(mainRule.clone(), clone of rulesWithParents); child.insert(depth+1, tail,...).
doInsertHere: parents None -> mainRule.acceptOverwrite; else rule with strArrCmp(rule.parents, parents)==0 -> acceptOverwrite; else fill fs -1/fg 0/bg 0 from mainRule, push new rule.
acceptOverwrite(d, fs, fg, bg): depth unless current greater; fs if !=-1; fg if !=0; bg if !=0.
trie.match(scope): non-empty and head child exists -> recurse; else rulesWithParents ++ [mainRule], stable-sorted by: depth desc; then loop { skip '>' in a; skip '>' in b; break if either out of range; return b[j].len16 - a[i].len16 if !=0; advance both }; then b.parents.len - a.parents.len. Cache per scope name.
Theme.match(path): None -> defaults. Else first rule of cached(path.name) whose parents match path.parent: empty matches; for each p: if '>' { false if last; take next, strict }; walk e while !matchesScope(e.name, p) { strict -> false; e = e.parent }; e None -> false; e = e.parent. Return Some((fs,fg,bg)) or None. matchesScope(name, pat) = pat==name || (name starts with pat && name[pat.len]=='.').

## Rules

BeginEnd: _begin = RES(begin, id); _end = RES(end || "", -1) (#252; 9.3.2 used "\uFFFF"); endHasBackReferences; applyEndPatternLast truthy. collectPatterns pushes _begin. Compiled list (lazy): collect each pattern; then end (clone if backrefs) pushed if applyEndPatternLast else unshifted. Every compileAG with backrefs: setSource(last or 0, endRegexSource).
BeginWhile: _begin; _while = RES(while, -2); whileHasBackReferences. patterns list = only patterns. while list = [_while (clone if backrefs)], then if backrefs setSource(0, endRegexSource or "") (#252; 9.3.2 used "\uFFFF").
registerRule: id = ++lastRuleId; during factory getRule(id) is None (RefCell<Vec<Option<Rc<Rule>>>>; no borrow held during factory).
getCompiledRuleId(desc, g, repo): desc.id if !=0. Else register; factory sets desc.id first, then: match truthy -> MatchRule(name, match, caps(captures)). Else begin absent (undefined; "" counts present): if desc.repository, repo = merge(repo, desc.repository); patterns = desc.patterns, or [{include}] if absent and include truthy; IncludeOnly(name, contentName, compilePatterns(patterns, repo)). Else while truthy -> BeginWhile(name, contentName, begin, caps(beginCaptures||captures), while, caps(whileCaptures||captures), compilePatterns(patterns)). _compileCaptures(caps): if truthy: max = max parseInt(keys) (start 0); fill [0..=max] None; per key in JS order: retok = caps[k].patterns present ? getCompiledRuleId(caps[k], g, repo) : 0 FIRST, then register CaptureRule, place at parseInt(k) (NaN registers, not placed).
_compilePatterns: per pattern with truthy include: $base/$self -> compile repo[include] with repo; #name -> repo[name] if present; scope / scope#name -> ext = g.getExternalGrammar(scope, repo); with name compile ext.repository[name] if present (with ext.repository), else ext.repository.$self (with ext.repository). No include -> compile pattern itself. If id != -1: skip if rule exists, is IncludeOnly/BeginEnd/BeginWhile, hasMissingPatterns and 0 patterns; else push. hasMissingPatterns = (patterns.len or 0) != result.len.
RegExpSource(src, ruleId): only non-empty string scanned; on '\' + next: z -> `$(?!\n)(?<!\n)`; A or G -> hasAnchor; skip next. hasBackReferences = `\\\d+` in transformed source. ## tokenizeString
_tokenizeString(g, str, isFirstLine, linePos, stack, lt, checkWhile); lineLength = len16; anchor = -1.
checkWhile -> _checkWhileConditions: anchor = stack.beginRuleCapturedEOL ? 0 : -1; collect BeginWhile nodes top->root, process root first: r = compileWhileAG(node.endRule, isFirstLine, linePos==anchor).find(str, linePos); None or id != -2 -> stack = node.parent; break. Else if captures: produce(node, c0.start); handleCaptures(node, whileCaptures); produce(node, c0.end); anchor = c0.end; if c0.end > linePos { linePos = it; isFirstLine = false }.
Loop: r = stack.rule.compileAG(stack.endRule, isFirstLine, linePos==anchor).find. Injections: cnsl scope names; best = MAX; each injection whose matcher matches: getRule(inj.ruleId).compileAG(None, ...).find; skip if None or start >= best; else record; break if best == linePos. priorityMatch = best.priority == -1. Injection wins if injStart < rStart || (priorityMatch && equal); r None -> injection.
No match: produce(stack, lineLength); stop. hasAdvanced = c0.end > linePos.
End (-1): produce(stack, c0.start); stack = withCNSL(stack.nameScopesList); handleCaptures(stack, popped rule endCaptures); produce(stack, c0.end); p = stack; stack = p.parent; anchor = p.anchorPos; if !hasAdvanced && p.enterPos == linePos { stack = p; produce(lineLength); stop }.
Else: rule = getRule(id); produce(stack, c0.start); before = stack; ns = stack.cnsl.pushAttributed(rule.getName(content, caps)); stack = stack.push(id, linePos, anchor, c0.end == lineLength, None, ns, ns).
 BeginEnd: handleCaptures(beginCaptures); produce(c0.end); anchor = c0.end; stack = withCNSL(ns.pushAttributed(getContentName)); if endHasBackReferences stack = withEndRule(resolveBackRefs(content, caps)); if !hasAdvanced && before.hasSameRuleAs(stack) { stack = pop; produce(lineLength); stop }.
 BeginWhile: same with while.
 Match: handleCaptures(captures); produce(c0.end); stack = pop; if !hasAdvanced { stack = safePop; produce(lineLength); stop }.
Then if c0.end > linePos { linePos = it; isFirstLine = false }.
handleCaptures(stack, captures, caps): return if captures empty; n = min(len, caps.len); maxEnd = c0.end; local = []. Per i: skip if capture rule None or len 0; break if start > maxEnd; while local.top.endPos <= start: produceFromScopes(top) & pop; local non-empty -> produceFromScopes(top.scopes, start) else produce(stack, start). retok != 0: ns = stack.cnsl.pushAttributed(getName); cs = ns.pushAttributed(getContentName); pushed = stack.push(retok, start, -1, false, None, ns, cs); recurse _tokenizeString(OnigString(substr16(0, cap.end)), isFirstLine && start == 0, start, pushed, lt, false); continue. ## Registry and dependencies (captures NOT walked)
SyncRegistry: addGrammar(raw, inj) by raw.scopeName (+ injections when Some); lookup, injections, themeMatch, getDefaults, grammarForScopeName (cached).
_loadGrammar: Q = [TopLevel(initial)]; seenFull = {initial}; while Q non-empty: load each scope (cached; addGrammar(raw, getInjections(scope)) when found); processQueue.
processQueue: take Q, reset; new collector (dedup by key scope or scope#rule; visited rules by Rc ptr); collectReferences per request; per collected: TopLevel -> skip if seenFull else add seenFull + Q; Partial -> skip if scope in seenFull or key in seenPartial else add seenPartial + Q.
collectReferences(ref): self = lookup(ref.scope); missing: throw if scope == initial else return. base = lookup(initial). TopLevel -> l({base, self}); Partial -> c(rule, {base, self, repo: self.repository}). Then TopLevel for each injections(ref.scope).
l(ctx): walk self.patterns (if array) and self.injections values, repo = self.repository. c(name, ctx): walk [ctx.repo[name]] if exists.
u(rules, ctx): per unvisited rule: repo2 = rule.repository ? merge(ctx.repo, rule.repository) : ctx.repo; walk patterns with repo2. include: $base -> l({...ctx, self: base}); $self -> l(ctx); #n -> c(n, repo2); scope ref: s = self if scope is self's, else base if base's; found -> c(n, {base, s, repo2}) or l({base, s}); else add Partial(scope, n) or TopLevel(scope).
parseRawGrammar: .json -> JSON; else plist. Plist: skip BOM, <?...?>, <!--...-->, <!...>; dict, array, key, string, integer, real, true, false, date, data; <x/> -> ""; entities &#N; &#xH; &amp; &lt; &gt; &quot; &apos;.

## Fonts and time limit
FontAttribute {fontFamily, fontSize, lineHeight}; theme rules parse fontFamily/fontSize/lineHeight (defaults ""/0/0). with(style): self when no style field is JS-truthy, else replace each truthy field. Root font = defaultFont.with(theme.match(root)); pushing a scope maps the parent's font through .with(match). Elements rebuilt by fromExtension (applyStateStackDiff) get null fonts, like upstream. LineFonts: skip when the scope list has no font or none of its fields is truthy; merge with the previous range when adjacent and options equal; zero-length ranges possible.
Time limit: checked at the top of each scan iteration; on timeout return the current stack with stoppedEarly = true. Nested capture retokenization passes 0 (no limit). 0 = no limit. A single scan can overshoot the limit.

## Rust design
Json enum, objects Vec<(String, Json)>. RawRule Rc: id Cell<i32>; name, contentName, match, begin, end, while, include: Option<Rc<str>>; captures/beginCaptures/endCaptures/whileCaptures: Option<Rc<RawCaptures>> (Vec<(Rc<str>, Rc<RawRule>)>; JSON null -> empty, like JS's clone(null) = {}); patterns Option<Rc<Vec<Rc<RawRule>>>>; repository Option<Rc<RawRepository>> (FxHashMap); all in raw.rs; applyEndPatternLast; grammar-level scopeName, injections (JS order), injectionSelector. Rule: struct with id, name/contentName + flags, kind enum, RefCell caches. Positions UTF-16 throughout.
Release profile: lto = true, codegen-units = 1.
